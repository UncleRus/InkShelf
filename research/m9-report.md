## 2. Приёмочный №13 — холодный старт и поиск

### Холодный старт (норма ≤ 3000 мс)

`am start -W` после `am force-stop`:

|---|---|

### Поиск (норма ≤ 300 мс)

## 4. Приёмочный №7 — обрезка при максимальном шрифте

Статически: в `row_book*.xml` нет `maxLines` / `ellipsize` / `singleLine`.

Динамически (`uiautomator dump`, вкладка «Все книги»):

| fontScale | Строк на странице | Высота title | Выход за список | Наложения |
|---|---|---|---|---|
| 1.0 | 5 | 50 px | 0 | 0 |
| 1.5 | 4 | 75 px | 0 | 0 |
| 2.0 | 2 | 100–174 px | 0 | 0 |

### Найденный и исправленный баг

До правки при `fontScale = 2.0` последняя строка страницы **обрезалась**: например,
на странице поиска «Zelazny» третья строка начиналась на `y=1121` и уходила за низ
списка (`y2=1265`), `book_meta` вообще не был виден. Причина — `PagePlan` считает
границы страниц по **номинальной** высоте строки (разметка с коротким образцом),
а длинное название переносится на 2–4 строки и строка становится выше.

Исправление: `ui/PageFit.java` после отрисовки страницы суммирует фактические
высоты строк; при переполнении поднимает кэш высоты `ListMetrics` до самой высокой
строки и перестраивает страницу (`MainActivity`, `GroupBooksActivity`). Подъём
монотонный, цикл сходится. После правки при 2.0 на странице 2 строки, всё в границах
списка; `test-clip.py` дополнен проверкой вертикального выхода.

## 5. AVD

Профиль `ink30` (1264×1680, density 300) используется для отладки вёрстки.
Образ API 30 в SDK отсутствует; AVD собран на `android-34/default/x86_64`
(поведение вёрстки от API не зависит, `minSdk 23`).

## 6. Воспроизведение

```bash
# 1. Синтетика (на хосте)
python3 research/gen-synthetic.py -n 100000 -o /tmp/opencode/synth --seed 42

# 2. На устройство (одним архивом быстрее, чем 100k файлов по одному)
tar -C /tmp/opencode/synth -cf - . | adb shell 'mkdir -p /sdcard/Synth100k && tar -C /sdcard/Synth100k -xf -'

# 3. Корень добавляется в S9 «Папки с книгами» → S5, затем S4.8 «Пересканировать»

# 4. Замеры
python3 research/profile.py --serial 6C766334 --cold-runs 3
python3 research/test-clip.py --serial 6C766334
```

`adb shell input text` не умеет кириллицу, поэтому автоматические запросы поиска —
латинские (в синтетике есть латинские авторы). Корректность FTS4 + `unicode61`
для кириллицы проверяет встроенный `FtsSmokeTest` («вой*», «Толстой», «1984»).
